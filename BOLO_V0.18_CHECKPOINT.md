# Bolo v0.18 — Player + Narrator Voices

Official Kokoro v1.0 narrator pack:
- Onyx — American male (default)
- Michael — American male
- George — British male
- Fenrir — American male
- Heart — American female

Player UI:
- large Play/Pause control
- Stop control
- progress indicator
- ready-ahead display
- narrator dropdown
- compact speed menu
- secondary Edit card for text
- narrator and speed persist across launches

Adaptive listening reserve:
- 1.0x: 12 s initial / 45 s target
- 1.25x: 30 s initial / 90 s target
- 1.5x: 60 s initial / 180 s target
- 1.75x: 90 s initial / 240 s target
- 2.0x: 120 s initial / 300 s target

The larger fast-playback reserve addresses the gaps observed at 1.5x without
increasing Kokoro synthesis speed or pushing the CPU harder.
